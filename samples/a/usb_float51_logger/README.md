# usb_float51_logger

用于测试 `SYNC ID 0x0101` 的 USB 控制包是否正确触发。

这个例程会：
- 接收 7 个 `float` 的控制包
- 将前 3 个 `float` 解码为 48 个按钮位图
- 打印按钮的 `PRESSED` / `RELEASED` 事件
- 同时打印 `lx/ly/rx/ry` 当前值，便于确认摇杆数据

协议布局：
- `[0]` 按钮 `0..15`
- `[1]` 按钮 `16..31`
- `[2]` 按钮 `32..47`
- `[3]` `lx`
- `[4]` `ly`
- `[5]` `rx`
- `[6]` `ry`
